# raga

Kumpulan aplikasi web internal. Setiap aplikasi berada di foldernya sendiri dan berupa satu file HTML yang bisa langsung dibuka di browser, tanpa instalasi.

## Daftar aplikasi

| Folder | Aplikasi | Keterangan |
| --- | --- | --- |
| [`kpi/`](kpi/) | Key Performance Indicator | KPI berjenjang dari CEO, Division Head, Unit Head, hingga Staff |

## Cara membuka

1. Unduh repository ini (tombol **Code** lalu **Download ZIP**) dan ekstrak.
2. Buka folder aplikasinya, lalu klik dua kali file `index.html`. Aplikasi terbuka di browser.
